# WarGames Neons Markers

A neon‑glow, 1980s‑inspired QGIS marker symbol collection based on vector‑display aesthetics and classic arcade‑era visuals.  
This pack recreates the iconic look of the 1983 film _WarGames_ and John Nelson’s ArcGIS Pro 80s movie map style.

---

## 📌 Overview

This QGIS style provides a full set of outline‑based, glowing point symbols designed for dark or black map backgrounds.  
The aesthetic is intentionally retro: vector displays, synthwave colors, and classic geometric shapes.

The style is described on the QGIS Hub as:

> “Ah, the 1980's... What a lovely time period. We've got big hair, big synths, CD's, arcades, and vector displays!”

It is **inspired by John Nelson’s 80s movie map style** and the film _WarGames_ (1983).

---

## 🎨 Style Characteristics

-   **Outline‑based shapes** with:
    -   Outer glow
    -   Thin white center line
-   Optimized for **dark/black backgrounds**
-   **Point/marker symbols only** (no lines or fills)
-   **Six color variants** for nearly all symbols:
    -   Blue
    -   Green
    -   Orange
    -   Pink
    -   Red
    -   White

---

## 🧩 Included Symbols

All symbols except one come in six colors. The set includes:

-   Big circle _(white only)_
-   Big circle with triangle
-   Cross
-   Diamond
-   Rectangle
-   Small circle
-   Square
-   Triangle
-   X

Bonus points if you know what “VG” means.

---

## 📥 Installation

1. Download the style from the QGIS Hub:  
   **[https://hub.qgis.org/styles/153](https://hub.qgis.org/styles/153)**
2. Open QGIS
3. Go to **Settings → Style Manager**
4. Click **Import**
5. Select the `.qml` or `.xml` file
6. The symbols will appear under **Marker Symbols**
