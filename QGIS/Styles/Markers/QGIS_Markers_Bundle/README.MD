# QGIS Markers Bundle: Temaki + Maki

A complete, CC0‑licensed collection of **all Temaki** and **all Mapbox Maki** icons packaged together as a unified QGIS symbol library.

This bundle provides two of the most widely used open‑source cartographic icon sets, fully parameterized for QGIS and ready for point‑of‑interest mapping, thematic symbolization, and professional cartography.

---

## 📌 Included Collections

### **Temaki Icons (Full Collection)**

Source: OpenStreetMap iD Editor  
License: **CC0**  
Official QGIS Style Page: [https://hub.qgis.org/styles/126](https://hub.qgis.org/styles/126)  
Icon reference: [https://ideditor.github.io/temaki/docs](https://ideditor.github.io/temaki/docs)

Temaki is a comprehensive set of POI icons designed for clarity at small sizes.  
The full collection includes icons for transport, amenities, natural features, hazards, recreation, and more.

---

### **Mapbox Maki Icons (Full Collection)**

Source: Mapbox Maki Icon Set  
License: **CC0**  
Official QGIS Style Page: [https://hub.qgis.org/styles/121](https://hub.qgis.org/styles/121)  
Icon reference: [https://labs.mapbox.com/maki-icons](https://labs.mapbox.com/maki-icons)

Maki is a widely adopted icon library used in web maps and mobile apps.  
The full set includes scalable SVG icons for urban features, services, landmarks, and navigation.

## 📥 Installation

### **Option 1 — Import QGIS Style Files**

1. Open QGIS
2. Go to **Settings → Style Manager**
3. Click **Import**
4. Select `temaki.qml` and `maki.qml`
5. Icons will appear under **Marker Symbols**

---

## 🧭 Usage

1. Open **Layer Properties → Symbology**
2. Choose **Single Symbol**, **Categorized**, or **Rule‑based**
3. Select icons from:
    - **Temaki**
    - **Maki**
4. Adjust:
    - Size
    - Fill color
    - Stroke color
    - Rotation
    - Data‑defined overrides

Both sets are designed to remain crisp even at small sizes (12–16 px).
