# QGIS Style: ArcGIS Random Colors

A lightweight, CC0‑licensed color ramp style for QGIS inspired by ArcGIS’ random color behavior.  
This repository provides documentation, usage guidance, and attribution for the style published on the official QGIS Hub.

🔗 **Style Page:** [https://hub.qgis.org/styles/151](https://hub.qgis.org/styles/151)

---

## 📌 Overview

The **ArcGIS Random Colors** style is a QGIS color ramp designed to quickly assign visually distinct colors to layers.  
It is ideal for thematic maps, exploratory data analysis, and any workflow where fast, readable color differentiation is needed.

**Style Type:** Color Ramp

## 🎨 Features

-   Generates **randomized, visually distinct colors**
-   Works with **any vector layer**
-   Compatible with **QGIS 3.x**
-   Lightweight and easy to customize
-   Fully **open and unrestricted** thanks to the CC‑0 license

## 📥 Installation

1. Download the style file from the QGIS Hub page:  
   [https://hub.qgis.org/styles/151](https://hub.qgis.org/styles/151)
2. Open QGIS
3. Go to **Settings → Style Manager**
4. Click **Import**
5. Select the downloaded `.xml` or `.qml` file
6. The style will now appear under **Color Ramps**

---

## 🧭 Usage

Once imported, you can apply the color ramp to any layer:

1. Open **Layer Properties**
2. Navigate to **Symbology**
3. Choose **Categorized** or **Graduated**
4. Select **ArcGIS Random Colors** from the color ramp dropdown
5. Apply and enjoy the randomized palette
