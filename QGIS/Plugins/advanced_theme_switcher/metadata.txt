Clicking a theme applies it via QGIS's normal QgsMapThemeCollection.applyTheme() (so all standard theme behaviour is unchanged), and sets a project-level expression variable, current_theme, to that theme's name. That variable is then readable as @current_theme in any expression anywhere in the project (symbology, labels, field calculator, etc.), letting you build styling logic that depends on which theme is currently active.
