# QGIS Processing Models

Reserved for QGIS Model Builder (`.model3`) workflows.

No models have been published here yet. To add one, export it from QGIS's
Model Builder (**Model → Export → Model as Image/Model File**), place the
`.model3` file in its own subfolder here, and add a short `README.MD`
describing what it does and how to load it (**Processing Toolbox → Add
Model to Toolbox**).
